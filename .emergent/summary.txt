**Key Technical Concepts**
- **Unified Sync Engine:** The proposed architecture combining push-based webhooks (for speed), polling (for safety), a full historical crawl (for reconciliation), and push-back (for data authority).
- **Bidirectional Data Sync:** A pattern where changes can flow in both directions between two systems. In this case, Trinity reads from Atlas but also writes changes back to Atlas, which remains the single source of truth.
- **Data Reconciliation:** The process of comparing data between two systems and resolving any discrepancies. This is the purpose of the full crawl layer and the on-demand health audit.
- **Workload-Balanced Assignment:** The least tickets assignment strategy, which assigns new work to the agent with the smallest current workload, promoting a more even distribution of tickets.
